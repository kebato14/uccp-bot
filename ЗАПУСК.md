# Как запустить бота

## Первый запуск на новом компьютере/сервере

```bash
cd "/Users/mos/Desktop/TO UDSP"
/opt/homebrew/bin/python3.12 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python -m uccp_bot.bot
```

Токен уже записан в файл `.env`. База данных `uccp.db` создастся сама
при первом запуске вместе со справочниками.

## Остановить

Ctrl+C в окне, где запущен бот, либо:

```bash
pkill -f uccp_bot.bot
```

## Что сделать сразу после запуска

1. Отправьте боту `/id` и впишите номер в `.env` → `BOOTSTRAP_ADMIN_IDS=`.
   Это единственный способ получить права администратора — сам себе роль
   назначить нельзя. Перезапустите бота.
2. Раздайте сотрудникам ссылку на бота. Каждый отправляет `/start` и заполняет
   имя, фамилию, должность и место работы.
3. Вам приходит заявка на регистрацию — проверяете человека и нажимаете
   ✅ Подтвердить, затем назначаете роль (и направление, если это мастер).
4. Мастерам пропишите телефон и @username: ⚙️ Администрирование →
   👥 Пользователи. Тогда бот узнает мастера автоматически при первом `/start`
   и сохранит его направления.

Все текущие пользователи бота сохранили доступ при обновлении — заново
регистрироваться им не нужно.

## Проверка без Telegram

```bash
.venv/bin/python tests/e2e_check.py      # бизнес-логика, оба сценария п.51
.venv/bin/python tests/ui_sim.py         # полная симуляция диалогов с нажатием кнопок
.venv/bin/python tests/gsheets_check.py  # содержимое месячного отчёта
.venv/bin/python tests/access_check.py   # разграничение доступа по ролям
```

## Google Sheets

Ежемесячный отчёт включается одним файлом-ключом — пошаговая инструкция
в `README.md`, раздел «Google Sheets». Пока ключ не подложен, отчёт за месяц
приходит администраторам файлом Excel.

## Круглосуточная работа

На рабочем компьютере бот живёт, только пока открыт терминал. Для постоянной
работы нужен сервер (VPS) — разверните там те же три команды и запустите бота
через `systemd` или `screen`.
